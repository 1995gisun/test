# AI 가상 고객 테스트단 (persona-qa)

다양한 고객 페르소나를 가진 AI가 **실제 브라우저로 쇼핑몰을 사용해 보고**, 어디서 막히는지 찾아내는 사용성 테스트 도구입니다.
테스트 시나리오를 단계별로 짜지 않습니다. **"생수 사고 쿠폰 적용해서 주문해"** 같은 목표만 주면, 각 페르소나가 자기 방식대로 시도합니다.

```
페르소나(personas.json) × 목표(goals.json)
        │
        ▼
 claude -p  ── Playwright MCP ──▶  브라우저 (녹화)
 (판단: 무엇을 보고 무엇을 누를까)      (실행: 클릭·입력·스크롤)
        │
        ▼
 result.json (성공/포기, 단계별 속마음, 발견한 문제)
        │
        ▼
 report.mjs ── AI가 이슈를 묶고 우선순위를 매김 ──▶ report.html
```

## 구성

| 파일 | 내용 |
|---|---|
| `shop/` | 데모 쇼핑몰. 사용성 함정 8개를 일부러 심어 둠 (`shop/TRAPS.md`가 정답지) |
| `personas.json` | 페르소나 정의. 이름, 기기(모바일/데스크톱), 화면을 볼 수 있는지, 최대 행동 횟수, 행동 규칙 |
| `goals.json` | 고객이 달성할 목표와 주문에 쓸 정보 |
| `run.mjs` | 페르소나 × 목표마다 Claude Code를 실행하고 결과와 녹화 영상을 `results/<실행시각>/`에 저장 |
| `report.mjs` | 결과를 모아 `report.html` 생성 |

## 기본 페르소나

| ID | 페르소나 | 특징 |
|---|---|---|
| `elder` | 김순자 (72세) | 모바일, 작은 글씨는 못 읽음, 전문용어 모름, 3번 헤매면 포기 |
| `blind` | 박민준 (전맹 시각장애인) | **스크린샷 사용 금지**, 접근성 트리(화면낭독기와 같은 정보)만으로 진행 |
| `foreigner` | Emily (미국인) | 영어와 기초 한국어만 이해 |
| `busy` | 이대리 (직장인) | 행동 15회 제한, 작은 글씨 안 읽음, 하이픈 넣어 전화번호 입력 |

페르소나는 `personas.json`에 항목을 추가하면 늘릴 수 있습니다. 규칙(`rules`)을 구체적으로 쓸수록 행동 차이가 뚜렷해집니다.

## 실행

```bash
npm install
node run.mjs                         # 전체 페르소나 × 전체 목표
node run.mjs --persona elder,blind   # 일부만
node run.mjs --repeat 3              # 조합마다 3회 → 성공률로 보고
node run.mjs --parallel 2            # 동시에 2개씩
node run.mjs --url https://stg.example.com   # 데모 쇼핑몰 대신 다른 사이트

node report.mjs results/<실행시각> --traps shop/TRAPS.md   # 데모: 함정 탐지율까지 표시
node report.mjs results/<실행시각>                         # 실제 사이트용
```

`results/<실행시각>/report.html`을 브라우저로 열면 페르소나별 결과, 우선순위 이슈, 단계별 속마음, 녹화 영상을 볼 수 있습니다.

### 준비물
- Node.js 18 이상
- Claude Code CLI (`claude`) 로그인 상태. 인증은 아래 중 무엇이든 됩니다. 코드를 바꿀 필요는 없습니다.
  - 시연·개인 PoC: Enterprise 계정 로그인 또는 `claude setup-token`으로 발급한 `CLAUDE_CODE_OAUTH_TOKEN`
  - 전사 운영: 회사 API 키(`ANTHROPIC_API_KEY`) 또는 Bedrock/Vertex 환경변수
- Chromium. Playwright 브라우저가 설치된 환경이면 자동으로 찾고, 아니면 `--browser <chrome 경로>`로 지정합니다.

## 페르소나가 "현실적으로" 행동하게 만드는 장치
- **도구 제한**: 페르소나는 브라우저 조작 도구만 씁니다. 자바스크립트 실행, 페이지 소스 읽기는 막혀 있습니다.
- **시각장애인 페르소나**: 스크린샷 도구 자체를 막아서, 접근성 정보가 없는 버튼은 실제로 찾을 수 없습니다.
- **모바일 페르소나**: 390×844 모바일 화면과 터치 환경으로 실행합니다.
- **행동 횟수 제한**과 **포기 조건**을 페르소나마다 다르게 둡니다.

## 실제 사이트에 적용할 때 주의
- 결제는 테스트 환경과 PG 테스트 카드로만 진행하세요. 운영 환경에서는 목표를 "결제 버튼 직전까지"로 쓰면 됩니다.
- 본인인증, CAPTCHA는 AI가 통과할 수 없으므로 테스트 환경에서 우회 설정이 필요합니다.
- AI는 매번 조금씩 다르게 행동합니다. 의사결정용 수치가 필요하면 `--repeat`로 여러 번 돌려 성공률을 보세요.
